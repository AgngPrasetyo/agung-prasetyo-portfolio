## About This Website

This portfolio website is built with plain HTML, CSS, and JavaScript. It is a static site, so it can be published for free with GitHub Pages without a VPS, paid domain, database, or build step.

### Preview locally

Open `index.html` in a browser, or use the VS Code Live Server extension for a local preview.

### Publish with GitHub Pages

1. Create a public repository on GitHub.
2. Upload the **contents** of this folder to the repository root, keeping `index.html` at the root level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Once deployment finishes, GitHub will show the published site URL in the Pages settings.

GitHub Pages hosts the portfolio and project screenshots. It does not run Flask or Python backends, so projects that need server-side functionality require separate hosting to be used as live applications.
